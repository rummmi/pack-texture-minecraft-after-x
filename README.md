# Pack texture Minecraft After X

Ce dépôt contient un pack de textures 64x64 inspiré du style Minecraft.

## Ce qui est inclus
- végétation : herbe, feuilles, bois, sable, pierre, eau
- objets : elytra, ender_pearl, torch, chest
- minerais : iron_ore, diamond_ore

## Fichiers importants
- `manifest.json`
- `textures/*.svg`

## Comment télécharger
1. Ouvre le dépôt GitHub sur ta tablette.
2. Clique sur `Code`.
3. Clique sur `Download ZIP`.
4. Ouvre le ZIP dans les fichiers de ta tablette.
5. Tu peux ensuite utiliser les images dans ton pack Bloxd.io.

## Important
Les textures sont des créations originales inspirées du style Minecraft, sans copier les assets officiels.
